# Separation models / 分离模型

The assistant uses `UVR-MDX-NET-Inst_HQ_3.onnx` for vocals/accompaniment and `UVR_MDXNET_KARA_2.onnx` for lead/backing estimation. Model parameters are frozen in `mdx-model-data.json`. Sources: [UVR model releases](https://github.com/TRvlvr/model_repo/releases/tag/all_public_uvr_models), [parameter registry](https://github.com/TRvlvr/application_data), and [UVR implementation](https://github.com/Anjok07/ultimatevocalremovergui/blob/master/separate.py).

The karaoke estimate from an already separated vocal stem is treated as backing content; the residual is treated as lead vocals. This does not identify individual singers. Leakage and missed parts require listening. Inference uses NumPy, SciPy and ONNX Runtime without opening a separation application's interface.

助手使用上述两个模型，先分离人声与伴奏，再估计主唱和和声。karaoke 模型在人声中估计的保留部分作为和声，残差作为主唱；它不能按歌姬身份准确分离，仍需试听串音与漏音。模型参数随包保存，推理无需打开分离软件界面。第三方授权见[英文说明](../THIRD_PARTY_NOTICES.md)与[中文说明](../THIRD_PARTY_NOTICES.zh-CN.md)。
