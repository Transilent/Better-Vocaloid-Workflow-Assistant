# 结构说明

```text
BVWA/
  启动助手.bat              便携入口，失败时显示日志
  app.py / publishing_ui.py  中文桌面界面
  pipeline.py               下载、续跑、分离、MIDI 编排
  mdx.py / separate_audio.py MDX ONNX 命令行分离
  midi_bridge.py            Vocal2Midi 推理桥接
  midi_merge.py             双声部合并，保持实际秒数
  cover_art.py              本家原始封面获取
  publication.py            成品验证、封面适配、简介快照
  publish_browser.py        Playwright DOM 上传辅助
  publish-selectors.json    平台网页控件配置
  dependencies/
    manifest.json           固定依赖 SHA-256 清单
    vocal2midi/              随包冻结的代码、Python、模型
    models/                 第一阶段 MDX 模型
    ffmpeg/                 FFmpeg
    browser/chrome/         私人便携环境中的浏览器程序
  models/                   第二阶段主唱 / 和声模型
  vendor/                   yt-dlp、Playwright 及 Node 驱动
  tests/                    使用合成素材的离屏回归测试
  tools/                    便携包构建、分卷合并、CPU 模式
```

源码快照保留已验证的 Vocal2Midi 接口版本，没有在打包时自动升级上游模型或代码。`requirements-runtime.lock.txt` 用于查看已冻结的 Python 包版本，单独执行 pip install 不会得到必需的模型和 native DLL。

运行时 `cache/` 保存模型缓存、临时文件和专用平台登录资料；`jobs/` 保存音视频及 MIDI；`publish-packages/` 保存发布资料。它们不属于干净发行包。备份个人历史时，请单独复制这些目录；登录会话仅用于原电脑，便携包不会携带。

程序内依赖采用相对路径，保存的内部历史路径支持 `@/` 标记。整包移动后不要只搬动 python.exe，也不要把依赖散放到其他目录。

页面更新可能使平台选择器失效。程序会保留已填写页面并提示人工处理；最终发布一直由人确认。
