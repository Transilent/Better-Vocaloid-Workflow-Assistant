# v0.4.1 · MIDI extraction fix

This patch fixes oversized audio slices that could stop MIDI extraction, especially when backing vocals contain short phrases separated by long silences. It also improves error details and download-source handling during upgrades.

## Fixed

- Turning off pitch-curve export now omits explicit pitch data and flat tuning presets from USTX, VSQX and SVP projects, including native intermediate files. Notes, lyrics and accompaniment are retained; changing the option refreshes cached project exports.
- Tiny vocal fragments now respect the maximum slice length when merged. Intervening silence is included in the calculation; fragments that cannot fit remain at their original timestamps.
- Error messages show the underlying exception and DirectML device-reset code when available. Normal GPU initialization messages no longer misclassify unrelated errors.
- The upgrade window retains the selected download source. Both download stages support GitHub direct connections and GitProxy, with fallback, resumable downloads and SHA-256 verification.

## Update from v0.3.1 or v0.4.0

Open **Settings/updates → Check for updates**, download the update and restart to install. The assistant selects the package matching the installed runtime. After the migration window finishes, it restarts into v0.4.1. Tasks, settings, platform sign-in profiles and installed optional models are retained. Original model weights are unchanged.

This release contains **update archives only**. Let the assistant select them; the individual ZIPs are not standalone installations. For a new installation, download the complete portable package from [v0.4.0](https://github.com/Transilent/Better-Vocaloid-Workflow-Assistant/releases/tag/v0.4.0), then update to v0.4.1.

## 简体中文

**0.4.1 修复了部分歌曲生成 MIDI 时反复失败的问题。** 短和声片段在合并时可能跨越较长静音，形成超过设定上限的切片。本次修复会计算完整时间跨度，保留无法合并的短片段及其原始位置，同时保留原有模型权重。

- 修复两个提取后端的短片段合并越界问题。
- 关闭音高线后，USTX、VSQX、SVP 及中间工程不再写入额外的音高曲线和平直调音预设；保留音符、歌词和伴奏。切换选项后会重新导出工程。
- 错误提示显示具体异常及可识别的 DirectML 设备错误，减少无关 GPU 日志造成的误判。
- 升级窗口沿用下载源设置；更新入口和后续增量包均支持 GitProxy 加速、下载源回退、断点续传和 SHA-256 校验。

**0.3.1 和 0.4.0 均可在线升级。** 在“设置与更新”中检查更新、下载并重启安装。助手会选择与现有运行库匹配的更新包，升级完成后自动重新打开。任务、设置、平台登录会话及可选模型会保留。

本次只发布更新包。首次安装请使用 [0.4.0 完整便携包](https://github.com/Transilent/Better-Vocaloid-Workflow-Assistant/releases/tag/v0.4.0)，再通过助手更新。请勿将单个更新 ZIP 作为完整软件解压运行。

Validation: the reported song completed all six stages on an RTX 5070 Laptop GPU using DirectML. Its maximum backing-vocal slice decreased from 64.56 s to 8.42 s, and the MIDI/SVP outputs passed validation. Both legacy upgrade paths are tested before publication.
