## 本次更新

- **调音工作流上线**：用可展开的步骤卡片代替连线，预设、分离、歌词校准、MIDI／工程、音频和字幕集中在同一页。支持网易云歌名／歌手搜索和本地参考歌词，网易云匹配默认用于主唱。
- **新增工程与音频导出**：接入 Vocal2Midi 2.0，保留中文和日语支持及原有 ASR 权重。支持汉字／拼音 MIDI、带音高线的 USTX、VSQX、SVP，以及 WAV、FLAC、MP3、OGG 分轨。输入 BV 号或导入音乐，即可准备可继续调音的 MIDI 和工程；支持音轨的工程格式会引用伴奏。
- **发布工作流上线**：成品与来源 → 封面 → 文案 → 上传，四步逐项检查。自动读取本家原始封面与简介，保留 STAFF 草稿，支持 B站和小红书上传。原封面按完整画面适配比例，最终发布仍由你在网页确认。
- **下载更顺畅**：新增经过校验的并行下载、断点续传和下载源切换。公共资料抓取默认直连，避免受失效代理影响。
- **修复与优化**：修复发布“下一步”的来源校验、工程导出选项联动、短音符被延长后出现重叠、进度停留在模型加载、压缩分轨削波等问题。优化缓存验证和音频处理内存占用；重新生成前会备份已经修改过的 MIDI、工程和压缩音频。
- **MIT 开源许可**：助手原创代码采用 MIT License；第三方组件与模型保留各自许可证和声明。

输出后请试听并检查歌词、音符与音高线，再继续调音。视频剪辑、最终音视频对齐和网页发布确认仍由用户完成。

## 从 0.3.0／0.3.1 在线升级

在旧版的**设置与更新**中检查、下载更新并重启安装。首次重启会进入升级窗口，下载新增依赖与程序文件，复用现有模型，完成后自动重启进入 0.4.0。支持 GitHub 直连和 GitProxy 加速，升级过程中保留设置、任务、登录会话和已安装的可选模型。

过渡入口约 10 KB，新增依赖与程序的下载约 **14.5 MB**，无需重新下载完整模型包。升级前请备份正在编辑的工程。遇到网络中断可重试或下次启动继续；安装失败会回滚本次文件替换。

## 首次安装

下载全部 `BVWA-Windows-x64.zip.001`、`.002`、`.003` 和 `release-assets.json`，放在同一目录。用 7-Zip 打开 `.001`，或使用 `Merge-PortableParts.ps1` 校验并合并，解压完整 `BVWA` 文件夹后双击 `BVWA.exe`。

`BVWA-App-Update.zip`、`BVWA-Runtime-Upgrade.zip`、`BVWA-Program-Update.zip` 供助手内部更新使用，不是独立安装包。GitHub 的 Source code 下载仅包含源码。BS-RoFormer 仍是可选组件，在“模型与组件”中按需安装。

## English

v0.4.0 introduces **Tuning workflow** and **Publishing workflow**. Expandable step cards replace the graph editor. Vocal2Midi 2.0 retains Chinese/Japanese transcription and the original ASR weights. NetEase song/artist search and local reference lyrics support calibration; pitch-aware USTX/VSQX/SVP projects and WAV/FLAC/MP3/OGG stems are available. Supported project formats reference the accompaniment.

Publishing now follows four pages: finished video/source, original cover, platform drafts, and account/upload. Creator pages remain open for human review and final publication. Downloads gain verified parallel transfer, resume and source selection. Fixes cover missing source navigation, dependent export controls, artificial short-note overlaps, inference progress and compressed-audio clipping. Modified outputs are backed up before regeneration.

**v0.3.0/v0.3.1 can upgrade online.** Check for updates, download and restart from Settings/updates. A compatible bootstrap downloads a roughly 14.5 MB runtime/program delta, reuses installed models and restarts into v0.4.0. Configuration, tasks, sign-in profiles and optional models are preserved. The migration supports direct GitHub downloads, GitProxy, verified resume and rollback.

New users need all three portable ZIP parts and `release-assets.json`. Open `.001` with 7-Zip, or verify/join using `Merge-PortableParts.ps1`, then extract and start `BVWA.exe`. The individual update ZIPs and Source code archives are not complete installations.
