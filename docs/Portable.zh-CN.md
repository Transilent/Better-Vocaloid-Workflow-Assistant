# VWA（术力口工作流助手）

[English](README.md) | [简体中文](README.zh-CN.md)

面向 Windows 的声库工作流助手，支持歌曲准备、SVP 调音、视频合成与上传资料准备。

## 开始使用

1. 从[发行页](https://github.com/Transilent/Better-Vocaloid-Workflow-Assistant/releases)下载全量包 `VWA-Windows-x64.zip` 或 JPN 包 `VWA-Windows-x64-JPN.zip`，解压到可写目录。解压后的顶层文件夹为 `VWA`；进入该文件夹启动 **`VWA.exe`**，并保留程序旁的配套文件夹。
2. 在**准备工作流**添加 B站 BV／链接或本地歌曲，核对分离、歌词、音符与输出后，点击**开始准备**。
3. 在**任务与结果**查看音频、MIDI 和工程，并继续中断任务；使用当前设置重做时会创建新任务。
4. 在**调音工作流**选择任务工程或导入 SVP，勾选轨道和一种主参数来源，另存为独立工程。风格、音高与曲线加密分别控制，强度可按 1% 拖动或直接输入。
5. 在声库编辑器中合成歌声，按需使用**合成视频**，或将已有成品直接交给**发布**。

使用结果前请核对音频、歌词与音符。最终发布由你在平台页面确认。

## 选择包型

| 包型 | 文件 | 用途 |
| --- | --- | --- |
| 全量包 | `VWA-Windows-x64.zip` | 包含中日文识别、音符提取与四个工作流 |
| JPN 包 | `VWA-Windows-x64-JPN.zip` | 保留相同工作流，不含中文 Qwen 权重，可使用日语识别和音符提取 |
| 更新包 | 以发行说明为准 | 升级兼容的已有安装，不能作为完整安装包使用 |

JPN 包请在准备工作流选择日语识别。需要中文歌词时，打开**模型与组件 → 中文歌词识别 → 下载中文模型**；已有文件可校验与修复。

如提供分卷，请将全部分卷与对应的 `portable-metadata-full.json` 或 `portable-metadata-jpn.json` 放在同一目录，并使用该包附带的合并工具。GitHub 的 Source code 不含完整运行库。

## 设置与输出

- 在**设置与更新 → 外观 → 界面语言**选择简体中文、日本語或 English，下次启动生效。歌词识别语言在准备工作流单独选择。
- 外观设置还提供浅色／深色、月光玻璃／纯色材质及界面缩放。
- 在设置或模型页面选择自动、直连或支持的加速来源，详见[下载来源](docs/DownloadSources.zh-CN.md)与[界面语言](docs/InterfaceLanguages.zh-CN.md)。
- 准备支持主唱／和声分轨、参考歌词、中文汉字／拼音、可选音高线和手动 BPM。MIDI、工程与音频可分别选择，在输出区域设置保存目录。
- 带时间轴的歌词可编辑并导出 SRT／WebVTT；无时间轴文本不会按总时长自动均分字幕。
- 设置中提供缓存管理，普通清理保留任务结果、模型和登录信息。

## 视频与发布

视频合成为可选步骤。选择已渲染的音频与视频，按需对齐后生成成品。

在发布中选择成品和来源任务，核对封面、标题与署名，再准备所选平台。本家封面来自 B站资料，自选图片与视频截图是独立选项；4:3／16:9 适配按需补边，保留完整原图。

上传资料准备完成后，在平台创作页面核对并手动发布。上传前请保留成品原位置，移动或修改后重新生成资料。

## 更新与排错

在设置与更新中按兼容路径升级。自动更新仅在启动时进行，安装后重启；提供的更新支持时，会保留设置、任务、登录和已安装模型。升级前请备份正在编辑的工程。

已有安装可按发行说明运行 **`VWA-Updater.exe`** 使用兼容升级工具。该工具不是完整便携安装包的一部分。

保留程序旁的 `dependencies`、`models`、`assets`、`components` 和 `vendor`。启动错误见 `launcher.log`；`tools/Start-Diagnostics.bat` 显示启动诊断，`tools/Check-Dependencies.bat` 检查运行库。JPN 缺少的中文模型可在需要时从模型页面安装。
