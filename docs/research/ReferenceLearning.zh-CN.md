# 工程参考学习

[English](ReferenceLearning.en.md) | [简体中文](ReferenceLearning.zh-CN.md)

研究工具用于对照带参数的 SVP 工程和本地参考人声，输出清单与离线评估报告。工具不会安装新的拟合配置、替换识别权重或改写参考工程。

## 工程审查

在已准备好的源码目录中，使用内置运行环境执行：

```powershell
dependencies\vocal2midi\python\python.exe -B tools\research\reference_corpus.py "path-to-reference-collection" work\reference-audit
```

参考集合包含 `svp_100/*.svp` 和 UTF-8 编码的 `svp_bilibili_map.csv`。对应表使用 `#`、`曲名/项目`、`投稿者`、`BowlRoll链接`、`B站链接` 列，工程文件名前的编号用于查找对应行。

审查只读取实际发声、被音轨引用的音符组，不将闲置的资料库快照和重复副本计为独立样本。全零曲线、固定偏移和所有音符一致的转换器默认值，不作为动态表现的证据。存在变化的曲线、非统一的音乐性音符或音素编辑，可以进入后续检查。这个分类只能说明工程中存在表现数据，不能证明每处修改都是人工调音或效果良好。

无效曲线会单独记录并排除，同工程内其他有效数据仍可使用。分析结束后重新核对输入文件哈希，输出保留排除原因、可用参数、声库、插值方式和来源哈希。

训练与留出集合按视频、规范化曲名和乐谱指纹分组。同谱的不同调音、UUID、整体移调或整体时间偏移，不会因此成为独立歌曲。这可以减少重复泄漏，但不能识别所有改编或翻译版本。

## 参数标签的含义

SVP 参数控制的是指定声库，不是对原唱的直接测量。相同的张力值在不同声库和合成版本中，响应可能不同。对应视频也可能是原唱、另一版翻唱、带效果的混音或短版；曲名一致不足以确认训练配对。

标签只取发声音符内的原始参数点。构造标签时，不用线性或 PCHIP 插值冒充编辑器原生三次插值的中间值。插值方式可参见[官方 Automation API](https://resource.dreamtonics.com/scripting/Automation.html)。

乐谱试验使用音符时长、句内位置、旋律上下文预测相对曲线形状。标签在音符组内去中位数，并按该试验的尺度归一化。工程等权，同工程的多个组共享权重，验证歌曲与训练歌曲分开。即使这项试验取得正向结果，也不能据此建立音频到声库参数的映射。

## 音频配对试验

先准备本地参考人声和经过校验的 RMVPE 音高侧文件，再对齐乐谱与人声，检查整条候选轨的时间偏移、移调、覆盖和音高一致性。较短或移调后的和声片段，不应挤掉覆盖更完整的主旋律；选中的轨道还必须实际带有待研究参数。

音频工具读取 JSON 清单，每项包含 `id`、`audio`、`pitch_cache`、`selection`。其中 `selection` 包含 `track_index`、`offset_seconds`、`transpose_semitones`、`score_voiced_coverage`、`pitch_agreement`、`compared_seconds`。音频路径相对清单解析。选择信息来自已记录的对齐结果，不能当作可随意调高的质量分数。

```powershell
dependencies\vocal2midi\python\python.exe -B tools\research\reference_audio.py work\reference-audit\corpus.json work\reference-audio-manifest.json work\reference-acoustic
```

试验复用已安装的 WORLD 组件和数值库，对谱倾斜、非周期能量、周期性、音量和音高进行声学分析。特征居中仅使用参考音频，不读取留出工程的参数标签。原始张力点还需要 WORLD 和 RMVPE 的局部音高依据，每音符采样上限可避免密集曲线占据过大权重。

预测目标是参数围绕本组中位数的变化，不含声库绝对偏置。去中位数是评估目标的定义，不能替代实际使用时缺失的声库偏置估计。主要模型采用固定正则化的线性拟合，另用相同特征和歌曲划分测试 pseudo-Huber 拟合对异常参数点的抵抗能力；固定的 0.02 控制单位平滑尺度和正则化系数不根据留出歌曲调整。验证时整首歌曲及其所有备选工程一起留出，不将同一录音的相邻帧分到训练和验证两边。在同一小批数据上比较这些候选仍属于探索，不能当作新的独立最终测试。

报告分别保留通过整曲配对的结果和仅有局部依据的探索结果。局部吻合不能让未通过整曲检查的样本变为已验证配对。现有保守映射以强度 1.0、未做声库校准的状态作为诊断对照。与人工控制曲线的误差衡量的是曲线一致性，不等同于听感或合成音频还原度。

## 使用研究结果

两项工具均写入 `runtime_enabled: false`，助手不会加载研究系数。候选方案需要更多独立、可靠的配对，针对目标声库验证，并在编辑器中控制变量重新渲染，才适合替换现有映射。拟合成功运行不代表效果改善，未通过的候选会保留在报告中。

参考工程、下载录音和私有文件路径不进入源码分发。来源和署名信息保留在本地；可以下载工程，不代表可以再分发其内容或衍生权重。此研究流程不增加识别或分离模型权重。
