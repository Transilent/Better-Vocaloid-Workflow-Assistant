# Simple mixing

Open “Simple mixing” in the sidebar and select up to three vocal WAVs rendered by the singing editor and one accompaniment. Adjust each track's level, pan and mute/solo; vocal tracks also have timing and reverb sends. Four-band EQ, compression and reverb act on the shared vocal bus. Presets are starting points for listening and adjustment. “Lock track settings” retains per-track pan and reverb sends when applying a preset; the preset still changes the vocal processing and overall reverb amount.

The assistant automatically prepares short A/B previews and updates them after parameter changes while trying to keep playback going. Seek across the song or loop the current segment. The before side retains track balance, timing and width, but bypasses vocal EQ, compression and reverb. This is buffered segment rendering, not zero-latency streaming; a small amount of audio beyond the segment is retained for limiter lookahead, and the reverb tail is measured near the end to update the playback duration. Finite reverb warm-up can still differ from a full export. If embedded playback is unavailable, the system player can be used. Meters report sample peaks and estimated block-energy gain reduction, not true peak or calibrated loudness.

Export a new WAV independently, or associate an existing task and explicitly register its Mixdown before video assembly. Source files are never overwritten. Confirm the sources again after switching tasks; files already exported remain at their original locations.

On first use, select “Install mixing component” in the mixing dialog. VWA downloads the pinned Pedalboard 0.9.26 Windows x64 wheel, verifies its size and SHA-256, extracts it under `dependencies/optional/pedalboard/current`, and probes its effects in an isolated subprocess. It does not modify the base Python site-packages. Download size is approximately 3.5 MiB; extracted runtime files use approximately 9.1 MiB. A network connection and write access to the application directory are required.

The pinned component and source are recorded in `components/pedalboard.json`; licence and static dependency details are in `components/pedalboard-THIRD_PARTY_NOTICES.md`. The existing v1.0.0 release predates this feature. Verify update compatibility and corresponding-source availability for the actual build before release; older updaters may require a compatible first hop or full package.
