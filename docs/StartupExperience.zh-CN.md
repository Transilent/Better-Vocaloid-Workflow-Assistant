# 启动提醒与入门教程

本页说明当前开发源码；GitHub 1.1.0 安装包不因源码推送而自动获得这些功能。

首次打开时，教程会遮罩实际程序窗口，依次介绍准备、组件、调音、简易混音、合成视频、发布和设置。可用“下一步 / 上一步”、左右方向键，或点击“跳过”及按 ESC 结束。完成与跳过都会记录在本机设置中；直接关闭窗口则下次继续提示。设置页的“重新查看入门教程”可随时重看，存在运行任务或弹窗时需先结束相应操作。

默认每次启动都在后台检查正式版更新。有新版本时显示版本、更新说明与用户 QQ 群 **490619616**。教程、其他对话框结束且主窗口回到前台后才弹出更新提醒。启动检查不会自行下载或安装。

- **立即更新**：兼容更新包走已有下载、完整性校验与安装流程；不兼容时打开对应发行页，由用户选择完整包。
- **下次再说**：默认下次启动提醒；也可选一小时、一天、七天、三十天后，或忽略此版本。同一会话不会重复弹同一版本；出现更高版本后重新提醒。
- 延后只影响弹窗，不阻止启动检查。设置中可手动检查，或用“恢复更新提醒”清除延后。
- 确认立即更新后，可按设置在下载校验完成后倒计时 10 秒重启安装。开始其他操作会暂缓；手动下载完成不会擅自重启。已下载但暂缓的更新在下次启动仍需确认安装。

设置页顶部“帮助与用户社区”可复制群号。教程最后一步和更新弹窗也会显示同一群号。

教程与提醒状态保存在本机 `config.json` 的 `startup_experience` 中，独立于可清理缓存。旧版 `startup_auto_update` 自动下载设置已移除；更新来源、检查开关与现有任务、预设配置保留。已有用户明确关闭启动检查时继续尊重该设置。

设置页的“GitHub 反馈与建议”会打开问题反馈、功能建议和使用求助的选择页，不收集或上传日志。提交前请检查正文、截图和日志，公开 Issue 的内容及附件可被他人访问。详见[反馈与日志说明](https://github.com/Transilent/Better-Vocaloid-Workflow-Assistant/blob/main/.github/SUPPORT.md)。
