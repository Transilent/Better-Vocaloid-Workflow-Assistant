# 合唱工作台

在一首歌里导入、对齐并修整多条真人干声。播放、波形、唱段选区与编辑由工程管理，切换全曲全览、唱段核对和单轨音高时沿用同一个播放位置。

## 从 Cubase 到分轨交付

1. 从 Cubase 导出干声与可选导唱、伴奏。共同起点最便于对回工程。直接将多条干声拖入合唱工作台，也可以点「干声」批量选择文件。独立导唱从「导唱」导入，伴奏从「伴奏」导入。不同长度、采样率可以放到同一个工程，通过右侧「起点」调整录音位置。
2. 为领唱、齐唱、上下和声填写声部，选一条有清晰发音的轨设为工程时间参照。需要交回这条轨时，把它的角色设为「待处理人声」并指定为时间参照。有自己的谱时导入 MIDI 或支持的歌声工程，在各轨「音高目标」中绑定正确谱轨。乐谱有前导留白或起点差异时调整「乐谱偏移」。
3. 在「批量处理」选择全组、同声部或本轨，以及整曲或选段。全组整曲默认按日语同词唱段对齐，可切换歌词语言或选择「按指定参照对齐」。对齐和修音的力度可分别调节。可以生成建议试听核对，也可以一次生成并应用。声音没有足够的对应证据时，会在待核对队列中显示原因。勾选「包含存疑建议」可一并应用仍有明确处理值的候选。无谱时修音参照本轨稳定音。
4. 点「待核对」定位，也可点击时间轴上的唱段。用右侧「唱段」核词与精修。唱段核对的下方是参照和待处理波形，拖动下方波形可调整整句时序，拖动菱形锚点可仅改局部。单轨音高显示源基频与当前试听曲线。独听、循环和四个试听版本使用同一播放头。按空格播放或暂停。
5. 点「分轨交付」选择版本以及整曲或选段。每次导出新建目录，生成同起点、等长的 32-bit float WAV，附带分轨 SHA-256、采样率、帧数和工程原点。同一遍渲染可附一份「合唱干声.wav」，按同一增益相加所有待处理人声，峰值将超过余量时统一衰减。带处理的交付在独立进程里逐轨渲染，完成后一次性发布结果目录。选段的工程起点记在「分轨说明.json」。把各条分轨放到 Cubase 的对应工程位置，再继续混音。

工程保存为 .vwachorus。它记录素材引用、分组、谱轨、参照、歌词、锚点、手绘曲线、选唱与增益。打开时会查验素材身份。原声、仅对齐、仅修音和处理后都以当前选唱为底稿。恢复主录音可撤销选唱。

## 校词、对齐与精修

全组整曲的同词模式根据各条待处理人声的发声区间分句。两条或以上的录音在同一时间有可靠的同词边界时，向共同位置靠拢。独唱或轮唱使用带有同词证据的导唱。手工指定的音轨或唱段参照优先。只靠导唱推断出的较大位移或局部拉伸进入待核对。自动识别结果作为草稿保存，已确认唱词和手工锁定的编辑沿用原值。

- 选中一句，填写「本轨」歌词，或选「同词共用」为这一句共用读音。日语识别使用本地 RomajiASR，普通话使用本地 Qwen3-ASR。识别结果进草稿，核对读音后用「确认歌词」写入工程。已确认的本轨歌词优先，其次是已确认的共用歌词。
- 在「本唱段时间参照」可选工程里的另一条人声或导唱，也可用「导入本句参照」选择人工修后的干声。新导入的唱段参照默认静音，只绑定所选唱段。需要对准不同导出的起点时，在轨道设置中调整参照起点。选好参照，可以确认共用歌词后点「分析本句」。
- 单句和批量先用可信元音估算整句平移，再检验局部拉伸能否解释平移后的时序差。有足够证据才会拉伸，平移优先保留句内时值。面板显示实际使用的参照、处理方式、边界数和中位余差。新证据确认原录音时序已接近时，可撤销该段已有的自动位移。右侧可选「自动 · 优先 TiFA」、TiFA 或 HubertFA，工程会保存选择。音素不足时有音符起音、声学起音或待核对结果。时间对齐支持不同音高的上下声部。
- 可直接编辑候选锚点，或把播放头放到字头后点「添锚点」。选择「单轨音高」并提取音高后，可用「画音高」覆盖发声区。「跟走势」从参照借用起伏并保留本声部音区，「跟音高」按参照的实测音高修正。自动重算保留手工编辑。需要重来可用「还原选段时间」或「还原选区」。
- 处理局部抢拍时，框选包含完整音符的唱段，把播放头放到音符上，再点「标记音符首尾」。若本轨还没有音高测量，工作台会先从干声提取。随后拖动下方波形的起点或终点锚点，修改该音的落点和时长。相邻锚点固定周围的时序。
- 右侧「唱段精修」可为一句调增益，或导入起点匹配的备选 take 并选唱。独听备选轨可以核对录音。备选轨用于替换原轨所选部分，输出仍是一条人声轨，交付说明会记录用到的备选素材。

## 按音节补力度

1. 选中一条待处理人声及唱段，到「唱段」核对并确认歌词，然后打开右侧「音节力度」，点「分析音节」。
2. 工作台按本轨的音素位置和波形找有声元音，以同一个人的邻近发声估算建议。力度较弱的有声段可获得最高 +4 dB 的初始建议。每行可点时间定位，并单独把补偿调到 0 或更高，手动上限随峰值余量变化，最高 +6 dB。保留有声段内的强弱曲线，补偿在边缘平滑进出。
3. 用「试听当前」和「试听建议」在同一位置独听对比。应用后可撤销、重做，或用「清除选区补偿」去掉所选音节的补偿。保存工程后会记录每个音节的曲线。「处理后」试听及分轨导出包含已应用的补偿。

音节补偿随原录音的发音位置移动，可以和原有的唱段增益叠加。切换备选录音会清除换录音范围里原有的音节补偿。分析沿用工程所选的音素引擎。

RMVPE、HubertFA 和语言识别使用现有本机模型。可选的 TiFA ONNX 运行库从完整本机模型目录读取。时间锚点拉伸、修音和试听渲染用同一个工程。小幅自动修音在持续发声段上改变音高，再用相位匹配的波形叠加恢复时长，平滑相邻修正量。组合处理用同时间位置的仅对齐波形识别并抑制新出现的短低频冲击。气口和手工指定的原声区间保留。手绘与大幅变调走 Rubber Band 连续变调并补偿启动延迟，变速由 Pedalboard 完成。重新渲染期间，播放仍沿用最近一份准备好的音频，状态行显示正在准备的版本。 [波形相似叠加方法](https://www.isca-archive.org/eurospeech_1993/roelands93_eurospeech.html)

TiFA 使用 `dependencies/vocal2midi2/models/tifa-1.0-onnx` 中的五个 ONNX 图、`config.json`、`vocabulary.json`、`dictionaries` 和 `assets`。可用 OpenVPI 的部署脚本转换官方权重，并保留原下载中的词典和 G2P 资产。权重标注为 CC BY-NC-SA 4.0。见 [官方模型发布](https://github.com/openvpi/TIFA/releases/tag/v1.0.0) 和 [上游 ONNX 接口](https://github.com/openvpi/TIFA/blob/v1.0.1/ONNX.md)。
