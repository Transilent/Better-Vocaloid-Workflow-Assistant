# 实验演唱风格预设

[English](StylePresets.en.md) | [简体中文](StylePresets.zh-CN.md)

在独立的**调音工作流**中选择已有任务或导入SVP，可试用 **柔和抒情、轻声叙述、有力流行**，设置强度及作用演唱轨。默认保留原表现，旧任务不会自动启用风格。调音选项不再依赖准备页面的工程导出开关；输入快照与恢复方式见[调音工作流](TuningWorkflow.zh-CN.md)。

这三项是试听草案：使用力度、张力、气声，以及适用时的发声强度。还可勾选“附加音高表现（实验）”，在原 `pitchDelta` 上添加局部增量。默认关闭音高表现，已有任务缺少此选项时按关闭处理。数值由人工设计，不是数据库学习系数、语义分类、目标声库实测校准或曲风保证，不写入另一声库专属的 Vocal Mode。不同声库和版本仍需实际验证。

|预设|候选方向|
|---|---|
|柔和抒情|柔和起收、适度展开句中主体、较克制张力、局部尾部气息。|
|轻声叙述|较轻音量、较低张力，保留持音有声核心，气息更多出现在起收部位。|
|有力流行|较有存在感的起音与持音核心、较少气声、受控收尾；不生成嘶吼或粗嗓。|

乐句窗口依据音符时间和间隙，不分析歌词语义。句内短间隙包含在所选窗口，较长休止保持原样。保留音符、歌词、时间、声库设置、retakes、伴奏、未知通道和未选轨。原控制点坐标保留，所选通道的值可以按明确实验包络发生增量变化；这与保形加密分开记录。原有长音变化保留，统一缩放包络增量来控制余量，不逐点截平峰值。

附加音高表现包括：柔和抒情较慢的句首轻滑入；轻声叙述短而克制的起音；有力流行较快的起音强调。相邻、不同音高的音符根据音程方向叠加短暂的衔接偏移，句末添加局部下探后归回原线。短音、重叠音和非演唱音不强加动作。轻声叙述不额外添加颤音；另外两项仅在长音已有音高变化很小、且音符明确关闭原自动颤音时试加小幅延迟颤动。原有或未知颤音状态保持，`vibratoEnv` 与音符颤音属性不改。

所有音高动作有独立时间窗口，窗口之外保留原分段线性函数；原 `pitchDelta` 时间坐标全部保留，窗口中的原值可按已记录的增量变化。已有非线性音高线整条保留并记为跳过。原值超出官方名义范围时保留该值，只舍弃受影响的动作，其余可用动作继续处理并记录部分应用。名义参数单位与插值定义见 [Dreamtonics Automation 文档](https://resource.dreamtonics.com/scripting/Automation.html)，文档没有提供本应用的风格数值配方。

已有非线性且非空的编辑器曲线、超出当前应用名义范围的原值保持原样，并报告部分应用/跳过原因。没有可修改通道时明确停止，原表现工程仍保留。首版只支持未裁剪的平铺 mainGroup；所选轨含库组引用时拒绝应用。

独立调音会话生成 `outputs/tuned-<签名>.svp` 与相邻 `.svp.tuning.json` 回执。兼容旧任务导出时，保留 `voices.svp`，另生成 `voices-style-<预设>-<签名>.svp`；旧生产回执按原机制标为非活动。换预设产生另一候选，重试从固定原表现开始，不叠加上次风格版本。用户改过的候选会先保留，再恢复生产输出。回执记录来源SHA、设置、实际通道、跳过原因、余量和加密结果。风格设置不会使ASR或MIDI推理缓存失效。

已有工程也可从应用根目录运行生成副本：

```powershell
dependencies\vocal2midi\python\python.exe -B style_presets.py A.svp B.svp --preset soft_ballad --strength 0.6 --tracks 0 --density dense
```

需要同时试用音高表现时，在命令后添加 `--style-pitch`。界面中同名开关会随工作流偏好保存；音高开关与相关源码哈希纳入候选缓存，不影响 MIDI 推理或原表现导出缓存。

命令拒绝覆盖原工程或不同的已有候选，另写 `.svp.style.json` 回执，并通过相邻回执拒绝将已知风格候选作为下一次输入。手动复制文件时需同时保留回执；回执丢失的候选无法仅凭工程内容可靠识别，请始终从原表现工程生成。应用内管线固定使用原表现基线，不从候选叠加。实际合成和试听由用户完成。

方向参考：[慢歌咬字案例](https://note.com/city_music55/n/nf53d5476edf1)、[局部轻声与气息案例](https://note.com/hiryukaoku/n/nedd8dbd1acc8)、[摇滚副歌案例](https://note.com/in_densetsu/n/n9e434e7d41af)。配方数值是本轮应用设计的试听草案，不是从这些文章复制的数值，也未在其他声库上校准。

选项与数值控件已取消滚轮改值，包括有焦点时。滚轮仍可滚动页面及浏览下拉列表；列表浏览不会提交新选项。鼠标点击与键盘操作保持可用。
