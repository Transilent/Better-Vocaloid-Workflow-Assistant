# 实验演唱风格

[English](StylePresets.en.md) | [简体中文](StylePresets.zh-CN.md)

在独立的**调音工作流**中选择已有任务或导入 SVP，可试用 **柔和〔实验〕**、**悲伤〔实验〕** 或 **明亮欢快〔实验〕**。默认保留原表现。整轨方式每次选择一个风格；时间片段方式可让不同非重叠片段分别选择，三者也都不在上一份风格候选上继续叠加。设置只在下一次重新生成候选时使用；打开、恢复或登记旧工程不会自动改写工程。

柔和侧重声线；悲伤侧重句中收敛和下行收尾；明亮欢快侧重清晰、利落的起音。风格由用户手动选择，不分析歌词，也不自动判定情绪。候选始终从已核验的原表现快照生成，换风格或重试不会从上一份候选继续叠加。输入快照与恢复方式见[调音工作流](TuningWorkflow.zh-CN.md)。

| 风格 | 标识 | 公开说明 |
|---|---|---|
| 柔和〔实验〕 | `gentle` | 声线方向：较轻起音、稳定有声核心与收弱的下行尾音。 |
| 悲伤〔实验〕 | `sad` | 情绪方向：清楚的有声核心、中段收敛与缓慢下行尾音，避免把整段变成更气声。 |
| 明亮欢快〔实验〕 | `bold` | 演唱表现：短促起音、清晰衔接与扎实持续段；保留原 `bold` 数值，只更新公开名称。 |

这些说明是待试听的参数方向，不是声库实测结论、听感保证或物理发声类别。配方由人工设计，不是语料学习系数、自动语义分类或目标声库校准；明亮程度、气声感和失真风险会随声库、版本与设置变化，实际效果须由用户合成并试听。

## 分段强度与细节

作用强度仍是一个总强度。新增的 `style_detail` 记录四个分段系数：

| 字段 | 作用对象 |
|---|---|
| `onset` | 音色与附加音高的起音 |
| `sustain` | 仅音色的持续段 |
| `connection` | 仅附加音高的局部衔接 |
| `release` | 音色与附加音高的收尾 |

四个系数均取 `0…1`，最终局部增量按“总强度 × 该段系数”缩放；未提供或旧记录缺少字段时补为 `1`。各系数只作用于上表列出的对象。关闭附加局部音高后，`connection` 不再产生音高动作；`onset`、`release` 的音色部分和 `sustain` 仍按设置生效。

音色侧使用力度、张力、气声及适用时的发声强度，在起音、持续和收尾加入平滑的加法变化。音高侧在起音、相邻音符衔接和收尾加入局部动作；原有曲线作为基线叠加，不把新配方冒充为原调音。短于 160 ms 的音符、rap/BR、静音及重叠音符不添加新的风格动作。音符、歌词、时间、声库设置、retakes、伴奏、未知通道和未选轨保留。

原控制点坐标保留；已有非线性且非空的曲线保持原样并记录跳过或部分应用原因。若应用后可能超出当前通道余量，程序按同一比例缩小各提案增量，避免把峰值逐点截平。风格处理不新增或改写颤音，也不改动 `vibratoEnv`、音符颤音属性或已经存在的颤音状态。

所有数值仍是手工编写的待试听草案。工程保护、可重复处理和报告通过只能说明处理边界，不能证明听感更好、没有失真，或具有统计意义上的风格效果。

## 整轨与时间片段

调音界面提供两种风格应用方式：

- **整轨**使用当前三个风格卡片之一，对所选实际目标轨应用一次风格增量。
- **时间片段**显示所选实际目标轨的音符，并在简易钢琴卷帘中横向框选时间。拖动建立选区，按 Esc 清除，按住 Ctrl 滚轮或使用按钮缩放。这里只用于查看音符和选择风格时间，不是完整的 MIDI 编辑器；不编辑音高、音节、歌词、节奏或声库。

在时间片段模式中，先框选有效时间，再设置风格、总强度、四段系数和附加音高，然后选择 **添加片段**。选择列表条目会把该片段的设置载回控件；**更新所选片段**、**删除所选片段** 和 **清空片段** 管理当前输入。片段不能重叠，最多 128 个，短于 25 ms 的选区不能成为片段。

片段列表非空时，执行只读取片段列表：每段可在自己的起止时间内使用各自的 `gentle`/`sad`/`bold`、总强度、四段系数和音高开关，区外保留主参数来源处理后的风格原线。此模式下顶部风格与分段控件是添加、更新片段的工具设置，不会另外生成一份整轨风格结果。参考、校准或沿用参数的主参数处理仍按所选实际目标轨的整轨范围执行。不同片段不重叠，候选仍从固定原表现开始生成，不在已有风格候选上继续叠加。

`style_regions` 只写入当前输入会话的执行 options，不进入通用工作流偏好。载入或更换输入会清空片段列表并回到整轨方式；恢复处理记录时只有输入 SHA 匹配才恢复片段，否则保持清空。片段处理不改变音符、音节、歌词、声库或时间。

## 默认音高与兼容映射

`gentle`、`sad` 与 `bold` 默认开启附加局部音高；用户显式关闭后，该选择保留。打开旧工程或旧候选文件不会自动改写文件中的风格设置或候选内容。恢复旧 ID 时，界面显示对应的合并卡，并保留已保存的总强度和显式 `style_pitch=False`；只有在旧记录缺少 `style_pitch` 时，才按原旧 ID 的默认值解释。用户随后保存偏好或重新生成候选时，新选择和结果使用 `gentle`、`sad` 或 `bold`。

| 旧 ID | 界面显示 |
|---|---|
| `soft_ballad`、`intimate_narration` | `gentle` |
| `melancholy`、`fragile_tender` | `sad` |
| `power_pop`、`bright_joy` | `bold` |

旧 ID 仍可从已有任务和旧命令行记录读取；六项不再作为独立界面卡片展示。

## 输出、回执与命令行

独立调音会话生成 `outputs/tuned-<签名>.svp` 与相邻 `.svp.tuning.json` 回执。兼容旧任务导出时，保留 `voices.svp`，另生成 `voices-style-<标识>-<签名>.svp`；旧生产回执按原机制标为非活动。新生成的回执、工作流设置与导出记录保存 `style_detail`。换风格产生另一候选，重试从固定原表现开始，不叠加上次风格版本。用户改过的候选会先保留，再恢复生产输出。回执记录来源 SHA、设置、实际通道、跳过原因、余量和加密结果。风格设置不会使 ASR 或 MIDI 推理缓存失效。

对已有 SVP 另存副本时，可选用 `--style-detail` 传入四段系数 JSON，并用 `--time-range START END` 指定项目秒数范围：

```powershell
dependencies\vocal2midi\python\python.exe -B style_presets.py A.svp B.svp --preset gentle --style-detail '{"onset":1,"sustain":0.8,"connection":0.6,"release":0.4}' --time-range 12.5 28.0
```

`--style-detail` 与 `--time-range` 均可省略；单次 CLI 范围之外保留原有风格线。`gentle`、`sad` 与 `bold` 默认包含附加局部音高，可用 `--no-style-pitch` 关闭音高而保留音色分段。旧 ID 仍接受，并按各自的旧配方和旧默认处理。

命令拒绝覆盖原工程或不同的已有候选，另写 `.svp.style.json` 回执，并通过相邻回执拒绝将已知风格候选作为下一次输入。手动复制文件时需同时保留回执；回执丢失的候选无法仅凭工程内容可靠识别，请始终从原表现工程生成。应用内管线固定使用原表现基线，不从候选叠加。合成和试听由用户完成，本功能不会自动推理或合成声库。

参数单位与插值定义见 [Dreamtonics Automation 文档](https://resource.dreamtonics.com/scripting/Automation.html)；该文档不提供本应用的风格数值配方。方向参考包括[慢歌咬字案例](https://note.com/city_music55/n/nf53d5476edf1)、[局部轻声与气息案例](https://note.com/hiryukaoku/n/nedd8dbd1acc8)、[摇滚副歌案例](https://note.com/in_densetsu/n/n9e434e7d41af)、[Synthesizer V 2 基本参数](https://sv2.docs.dreamtonics.com/zh/parameters)及[含泪与明亮表达的调声案例](https://note.com/ka_youtyu/n/n17cedba677e5)。这些来源提供控制语义与作业方向，不提供本应用的数值配方。

选项与数值控件已取消滚轮改值，包括有焦点时。滚轮仍可滚动页面及浏览下拉列表；列表浏览不会提交新选项。鼠标点击与键盘操作保持可用。
