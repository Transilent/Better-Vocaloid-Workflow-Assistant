# 调音方案、工程绑定与候选生成

[统一预设库](PresetLibrary.zh-CN.md)

调音工作流支持保存整轨调音方案，从本机库预览并绑定当前 SVP，随后生成独立候选。预设文件只保存参数；目标轨、参考音频、声库校准配置和沿用工程保存在本机处理记录中。导入仍默认附加，导入和预览不会生成工程。

## 操作流程

1. 在调音工作流调整参数，在“预设”页保存当前方案。填写名称后创建新的本机条目，可通过管理器导出 `.vwa-preset.json` 分享。同名可以共存。
2. 载入目标工程，在“预设”中选择调音方案并点击“查看差异”。选择目标演唱轨，填写方案所需的本机输入。
3. 确认应用只修改当前表单。参考音频、声部角色或沿用轨未填全时，允许先将方案应用为“待补输入”，生成按钮保持禁用。补齐输入后再生成。
4. 点击生成，使用现有调音事务写出独立 SVP 和回执。原工程及未选轨保留。同一处理记录的后续生成始终使用其不可变输入；同参数可复用已核验候选。
5. 修改处理参数后自动转为自定义，结果不再声称来自原预设；修改工程输入绑定则继续关联同一方案。也可“解除预设关联”保留当前参数。

| 表现来源 | 本机必需输入 |
| --- | --- |
| 保留工程参数 | 目标演唱轨。已有曲线保留，再按明确选择的风格或技法处理。 |
| 参考人声 | 每个目标轨的参考音频及声部角色。文件存在性和内容身份在执行时复核。 |
| 声库校准 | 逐轨参考音频、声部角色及当前乐谱/声库的校准配置。强度为零也要核对校准身份，不能借此绕过绑定检查。 |
| 沿用原参数工程 | 原参数 SVP 及每个目标轨对应的来源轨号。未选择来源轨时保持待绑定。当前页面一次使用一个来源工程。 |

## 使用外部风格

1. 在“预设”中附加导入 `.vwa-preset.json` 风格文件，选择带“风格”标记的条目。查看配方通道和默认强度，点“选用风格”。
2. 在“风格”中调节强度。给一段歌词加风格时，选好目标轨及时间范围，再点“应用到时间选区”。同轨新增片段覆盖重叠部分。没有已登记片段或改谱时，冻结预览将按选中的演唱轨处理整轨。
3. 点击“冻结预览”核对实际应用和跳过的通道，再生成、另存候选。短音、休止、重叠音符和已有非线性原生曲线按保护规则跳过。已有手绘音高随草稿一起进入候选。

外部 v1 配方支持音符相位上的力度、张力、气声和发声增量。各原生格式按自身通道支持范围处理。保存整轨调音方案时，可引用选中的配方。分享整轨方案时同时提供风格文件，接收方保留原始 ID、版本和内容才能匹配依赖。

## 基线、恢复与身份

载入能识别出调音/风格候选回执的 SVP 时，预设应用要求明确确认是否将该候选作为新基线。损坏或不匹配的同名回执也显示待确认。缺少回执仅表示没有发现回执，不能证明工程未被处理。

应用确认会重新核对工程 SHA、库条目的 ID/版本/原始字节 SHA、当前表单和绑定提案。变化时要求重新预览。控件无法准确表达方案时恢复原表单，包括隐藏行的绑定值。

处理记录冻结完整预设文档、摘要、本机绑定及实际执行参数。引用外部风格的方案同时保存依赖原文，库中的条目之后被删除，已有记录仍可恢复。回执和缓存绑定输入、选区、强度与配方身份。

## 维护边界

- `quick_tuning` 管理选择、草稿和预览状态，QML 展示状态并发送操作。
- `tuning_preset_documents` 解析并校验精确依赖，冻结方案和本机绑定。
- `style_presets` 解释有界配方曲线，沿用现有风格叠加和保护逻辑。
- `tuning_execution` 和 `tuning_workflow` 核对身份，提交及恢复经验证的独立候选。

没有第二套调音执行器。纯数据提案与实际候选共用 `tuning_engine.settings` 参数契约。合成、人工听感及音乐质量判断沿用独立验收流程。
