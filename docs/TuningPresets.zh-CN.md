# 调音方案、工程绑定与候选生成

[统一预设库](PresetLibrary.zh-CN.md)

调音工作流支持保存整轨调音方案，从本机库预览并绑定当前 SVP，随后生成独立候选。预设文件只保存参数；目标轨、参考音频、声库校准配置和沿用工程保存在本机处理记录中。导入仍默认附加，导入和预览不会生成工程。

## 操作流程

1. 在调音工作流调整参数，点击“保存当前调音方案…”。填写名称后创建新的本机条目，可通过管理器导出 `.vwa-preset.json` 分享。同名可以共存。
2. 载入目标 SVP，点击“从本机库选择并绑定工程…”。选择调音方案，查看参数差异，明确勾选目标演唱轨并填写所需输入。伴奏不能作为调音目标。
3. 确认应用只修改当前表单。参考音频、声部角色或沿用轨未填全时，允许先将方案应用为“待补输入”，生成按钮保持禁用。补齐输入后再生成。
4. 点击生成，使用现有调音事务写出独立 SVP 和回执。原工程及未选轨保留。同一处理记录的后续生成始终使用其不可变输入；同参数可复用已核验候选。
5. 修改处理参数后自动转为自定义，结果不再声称来自原预设；修改工程输入绑定则继续关联同一方案。也可“解除预设关联”保留当前参数。

| 表现来源 | 本机必需输入 |
| --- | --- |
| 保留工程参数 | 目标演唱轨。已有曲线保留，再按明确选择的风格或技法处理。 |
| 参考人声 | 每个目标轨的参考音频及声部角色。文件存在性和内容身份在执行时复核。 |
| 声库校准 | 逐轨参考音频、声部角色及当前乐谱/声库的校准配置。强度为零也要核对校准身份，不能借此绕过绑定检查。 |
| 沿用原参数工程 | 原参数 SVP 及每个目标轨对应的来源轨号。未选择来源轨时保持待绑定。当前页面一次使用一个来源工程。 |

整轨方案支持当前内置风格和技法。时间片段草稿保留原有入口，暂不导出为整轨预设。外部风格配方、未知能力或未解析依赖仍可在统一库保管，应用时明确拒绝，不自动下载或执行。

## 基线、恢复与身份

载入能识别出调音/风格候选回执的 SVP 时，预设应用要求明确确认是否将该候选作为新基线。损坏或不匹配的同名回执也显示待确认。缺少回执仅表示没有发现回执，不能证明工程未被处理。

应用确认会重新核对工程 SHA、库条目的 ID/版本/原始字节 SHA、当前表单和绑定提案。变化时要求重新预览。控件无法准确表达方案时恢复原表单，包括隐藏行的绑定值。

处理记录冻结完整预设文档、原始内容摘要、规范化摘要、本机绑定和实际执行参数。库中的条目之后被删除，已有记录仍可恢复；恢复损坏的关联时禁用生成，需重新选择方案或显式解除关联。回执与缓存签名共同绑定这些身份；预设变化、绑定变化或输入内容变化不能复用旧身份。

## 维护边界

- `tuning_preset_documents`：纯数据的保存、能力检查、待绑定清单和应用提案。
- `tuning_preset_ui`：名称、差异、目标轨和本机输入选择；不生成候选。
- `tuning_form_state`：页面保存、应用、恢复和执行共用的表单读写。控件是唯一可编辑状态。
- `tuning_preset_controller`：冻结当前方案及其身份；处理参数变化时解除身份，绑定变化时重建提案。
- `tuning_execution`：规范化参数、工程与校准身份、依赖摘要、回执关联检查。
- `tuning_worker`：启动前冻结参数和关联，后台不读取控件。
- `tuning_workflow`：沿用现有会话锁、不可变输入、候选提交、取消、恢复和登记事务。

没有第二套调音执行器。纯数据提案与实际候选共用 `tuning_engine.settings` 参数契约。合成、人工听感及音乐质量判断沿用独立验收流程。
