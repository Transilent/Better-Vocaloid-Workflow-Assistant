# 调音方案、工程绑定与候选生成

[统一预设库](PresetLibrary.zh-CN.md)

调音工作流支持保存整轨调音方案，从本机库预览并绑定当前 SVP，随后生成独立候选。预设文件只保存参数；目标轨、参考音频、声库校准配置和沿用工程保存在本机处理记录中。导入仍默认附加，导入和预览不会生成工程。

## 操作流程

1. 在调音工作流调整参数，在“预设”页保存当前方案。填写名称后创建新的本机条目，可通过管理器导出 `.vwa-preset.json` 分享。同名可以共存。
2. 载入目标工程，在“预设”中选择调音方案并点击“查看差异”。选择目标演唱轨，填写方案所需的本机输入。
3. 确认应用只修改当前表单。参考音频、声部角色或沿用轨未填全时，允许先将方案应用为“待补输入”，生成按钮保持禁用。补齐输入后再生成。
4. 点击生成，使用现有调音事务写出独立 SVP 和回执。原工程及未选轨保留。同一处理记录的后续生成始终使用其不可变输入；同参数可复用已核验候选。
5. 修改处理参数后自动转为自定义，结果不再声称来自原预设；修改工程输入绑定则继续关联同一方案。也可“解除预设关联”保留当前参数。

| 表现来源 | 本机必需输入 |
| --- | --- |
| 保留工程参数 | 目标演唱轨。已有曲线保留，再按明确选择的风格或技法处理。 |
| 参考人声 | 每个目标轨的参考音频及声部角色。文件存在性和内容身份在执行时复核。 |
| 声库校准 | 逐轨参考音频、声部角色及当前乐谱/声库的校准配置。强度为零也要核对校准身份，不能借此绕过绑定检查。 |
| 沿用原参数工程 | 原参数 SVP 及每个目标轨对应的来源轨号。未选择来源轨时保持待绑定。当前页面一次使用一个来源工程。 |

## 使用外部风格

1. 在“预设”中附加导入 `.vwa-preset.json` 风格文件，选择带“风格”标记的条目。查看配方通道和默认强度，点“选用风格”。
2. 在“风格”中调节强度。给一段歌词加风格时，选好目标轨及时间范围，再点“应用到时间选区”。同轨新增片段覆盖重叠部分。没有已登记片段或改谱时，冻结预览将按选中的演唱轨处理整轨。
3. 点击“冻结预览”核对实际应用和跳过的通道，再生成、另存候选。短音、休止、重叠音符和已有非线性原生曲线按保护规则跳过。已有手绘音高随草稿一起进入候选。

外部 v1 配方支持音符相位上的力度、张力、气声和发声增量。v2 可同时带有起音和收尾的相对音高。v3 增加单音和乐句包络，以及按唱段位置触发的唱腔动作。各原生格式按自己的可写通道处理。保存整轨调音方案时，可引用选中的配方。分享整轨方案时同时提供风格文件，接收方保留原始 ID、版本和内容才能匹配依赖。

## 从参考素材制作风格

1. 在左侧导航打开“调音工坊 → 风格制作 → 参考取材”。选择参考工程、演唱轨和唱段。使用“同谱前后对照”时另选调音前稿和对应演唱轨。使用“对齐干声”时选择 WAV，并填写干声 0 秒在工程中的位置。整首已对齐的干声通常为 0，截取文件填写该截取段原来的起点。
2. 点“提取风格”。力度按音符归一到 0–100% 相位，对多个音符取中位形状。干声会显示有效重合和可用音符数，包含明显错位的选段可以调整起点后重试。勾选提取音高时，WAV 使用随包 RMVPE 的有声帧和乐谱音符。工程使用可读取的原生控制点。休止、重叠、过短和选区切断的音符会被排除。
3. 拖动力度控制点，或按相位用滑块调节。起音和收尾采用带音分的短动作，每种幅度最多 120 音分，长度至多占目标音符的 40%，上限 240 毫秒。用强度滑块整体缩放。目标上的手绘优先覆盖同位置的风格音高。
4. 到调音单轨视图选一段目标唱词，再回工坊点击“试套当前选区”。试算使用正式候选的参数写回逻辑，确认后可应用并正常冻结、生成和另存。点“保存配方”添加到本机预设库，再从工坊的“预设库”导出。配方只携带编辑参数和作者填写的名称。

### 核对参考与承接准备人声

- 选择素材后点“核对参考”。同谱前后对照会检查两份工程的格式和选区内的速度轴，同时检查音符时间、音高、歌词及演唱状态，包括因为太短或重叠而未用于提取的音符。
- 对齐干声会显示文件时长、完整可用的音符数及逐音符覆盖。报告会区分超出文件范围与信号活动不足，覆盖不足时请调整偏移后再核对。按时域覆盖进行的检查无需运行音高模型。启用音高提取后，才会根据干声测量音高残差。
- 已有原曲时，在“对齐干声”点“去准备分离”，确认“仅分离音频”后选择输入并手动开始。准备完成可以点“为工坊选人声”，也可以从工坊点“从任务选人声”选已有准备任务。在任务与结果确认全人声、主唱或和声后点“带回工坊”。
- 带回的干声保留任务来源并复核文件和上游修订。工坊保留当前选择的参考乐谱、唱段及风格草稿。新带入的人声从偏移 0 开始，请按乐谱的起点检查实际时间。任务产物与本机路径留在工作区，导出的风格配方只保存参数。

## 制作新风格与唱腔

1. 在“调音工坊 → 风格制作 → 制作新风格”从空白草稿开始。可从参考取材页分别带入力度或起收音高，也可展开“参考旧配方”查看柔和、悲伤、明亮欢快、中文戏腔的做法。各草稿在本次打开 VWA 期间可来回切换。已有配方的颜色随新配方保存。
2. 在“表达包络”中切换力度、张力、气声和发声强度。单音包络控制起音、持续、收尾和长音展开，乐句包络补充句首、句中、句尾的变化。图上的两条线显示当前强度下的示例增量。目标音符的形状取决于实际时长和可写余量。
3. 在“唱腔动作”分别调整句首倚滑、音间衔接、句尾收腔和长音颤音。非零偏移或颤音幅度启用对应动作。颤音幅度使用半幅音分，只有满足时长、已知无显式颤音且局部音高平稳的音符会新增此动作。风格音高仍受目标格式、原生曲线和手绘层限制。
4. 选好目标唱段后试套，检查变化和跳过情况。结果有可写变化时才可应用到时间选区。在“预设库”可以导出 v3 配方，也可点“复制到风格制作”继续编辑后另存。接收方需要支持 `style-recipe/v3` 的 VWA。

## 使用声库拟合预设

1. 在“调音工坊 → 声库拟合”选择带目标声库的 SVP、对应演唱轨和从工程零点对齐的参考 WAV。准备七轨试音工程，然后在 Synthesizer V 按轨导出七份试音。
2. 等待 WAV 核验和拟合完毕，打开基准及拟合工程查看。输入名称并点“保存校准预设”。工坊会关联本机试音目录。
3. 打开匹配乐谱和声库设置的 SVP，在单轨视图选好目标演唱轨。从工坊预设库选用校准预设，确认调音来源和参考干声，再预览、生成、另存。导入他人的预设时，先关联该次校准的七份原始 WAV 所在目录。WAV 的摘要须与预设一致。

校准预设用于匹配的乐谱和声库设置。跨作品复用相对表现时，可在风格制作中从拟合工程采集风格配方。

### 命令行

在 VWA 安装目录用随包 Python 运行下面的命令。轨号从 0 开始，区间和干声偏移单位为秒。只用原生工程时可省略 `--audio` 和 `--audio-zero`，或用 `--before` 和 `--before-track` 读取同格式、同音符和同轴底稿的差值。

```powershell
.\dependencies\vocal2midi\python\python.exe .\style_authoring.py extract ref.svp demo.vwa-preset.json --name "柔和收尾" --track 0 --range 12 16 --audio vocal.wav --audio-zero 12 --pitch
.\dependencies\vocal2midi\python\python.exe .\style_authoring.py preview target.svp demo.vwa-preset.json --track 0 --range 22 25
```

## 基线、恢复与身份

载入能识别出调音/风格候选回执的 SVP 时，预设应用要求明确确认是否将该候选作为新基线。损坏或不匹配的同名回执也显示待确认。缺少回执仅表示没有发现回执，不能证明工程未被处理。

应用确认会重新核对工程 SHA、库条目的 ID/版本/原始字节 SHA、当前表单和绑定提案。变化时要求重新预览。控件无法准确表达方案时恢复原表单，包括隐藏行的绑定值。

处理记录冻结完整预设文档、摘要、本机绑定及实际执行参数。引用外部风格的方案同时保存依赖原文，库中的条目之后被删除，已有记录仍可恢复。回执和缓存绑定输入、选区、强度与配方身份。

## 维护边界

- `quick_tuning` 管理选择、草稿和预览状态，QML 展示状态并发送操作。
- `tuning_preset_documents` 解析并校验精确依赖，冻结方案和本机绑定。
- `style_presets` 解释有界配方曲线，沿用现有风格叠加和保护逻辑。
- `tuning_execution` 和 `tuning_workflow` 核对身份，提交及恢复经验证的独立候选。

没有第二套调音执行器。纯数据提案与实际候选共用 `tuning_engine.settings` 参数契约。合成、人工听感及音乐质量判断沿用独立验收流程。
