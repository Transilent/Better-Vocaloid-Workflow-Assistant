# 简易混音

在侧栏“简易混音”导入歌声合成软件导出的干声和伴奏，调整平衡及人声处理，试听后导出新的 WAV。最多可加入三条歌声干声及一条伴奏；每轨可调音量、声像和静音／独奏，每条歌声可调时间偏移及混响发送。四段 EQ、压缩和混响作用于人声总线，预设仅作为进一步试听调整的起点。“锁定轨道设置”会在应用预设时保留各轨声像和混响发送；预设仍会改变人声处理和混响总量。

选择素材后，助手自动准备 A/B 试听；调整参数时会在后台重新处理短片段，当前播放尽量继续，结果就绪后切换。可点击进度条定位整首歌、用循环重复当前片段；处理前保留轨道平衡、偏移及宽度，旁通人声 EQ、压缩和混响。该功能是有延迟的分段试听，不是零延迟音频流；片段边界会预留限幅器所需的后续采样，接近结尾时测量混响尾音并更新结束位置。混响预热采用有限历史，长尾与完整导出可能有差异。内嵌播放不可用时可调用系统播放器。电平为采样峰值，GR 是基于音频块能量差的估计值，并非真峰值或标准响度测量。

进度条点击会直接选择歌曲位置；拖动时光标和时间立即跟随，松手后执行一次定位。键盘和滚轮的连续调整会短暂合并。定位到当前片段之外时需要准备新片段，等待期间保留所选位置；此时可用播放／暂停按钮改变新位置就绪后的播放状态。按 Esc 或切换窗口可取消尚未提交的拖动。定位失败时保留目标，点击播放可重试。

可独立使用，也可关联已有任务，确认后登记为任务 Mixdown 并继续合成视频。源文件不会被覆盖，切换任务后应重新确认素材；已生成文件保留在原路径。

首次使用时，在混音界面点击“安装混音组件”。助手会下载 Pedalboard 0.9.26 Windows x64 wheel，核对固定的大小和 SHA-256，解包到 `dependencies/optional/pedalboard/current`，并在隔离子进程中检查效果链；无需修改基础 Python 的 site-packages。下载约 3.5 MiB，安装后的运行文件约 9.1 MiB。需要网络连接和应用目录写权限。

组件固定版本与来源见 `components/pedalboard.json`，许可证及静态依赖见 `components/pedalboard-THIRD_PARTY_NOTICES.md`。现有 v1.0.0 发行包没有此功能。发布前应验证实际构建的更新兼容性与对应源码提供方式；旧更新客户端可能不接受新增文件，应先验证兼容首跳或完整包。
