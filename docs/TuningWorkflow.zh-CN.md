# 准备工作流与调音工作流

[English](TuningWorkflow.en.md) | [简体中文](TuningWorkflow.zh-CN.md)

主流程为 **准备工作流 → 调音工作流 → 合成视频 → 发布**。视频合成继续可选，已有成品视频可直接进入发布。声库合成与最终发布仍由用户执行确认。

准备工作流负责在线/本地音乐、分离结果、歌词、MIDI和编辑器工程导出。保存的调音偏好不会自动作用于新准备的工程。兼容音符重生成时沿用已有参数仍是保留原调音，不等于重新拟合。

调音工作流独立选择已有任务的SVP或导入SVP，明确演唱轨和参考音频映射，再生成独立候选，不依赖准备页面是否开启MIDI或SVP导出。首版编辑格式为SVP；其他格式需先转换并核对，不能为了导入而静默丢失未知参数。

## 统一处理顺序

参数来源四选一：

- **保留原表现**：保留工程已有参数。
- **参考演唱映射**：由明确对应声部的音频生成所选力度、张力、气声、发声强度草案，不是克隆音色。
- **实测声库校准**：使用同乐谱、声库和渲染设置的配置，仍需用户先渲染试音。配置缺少某个原有参数通道的试音时，不能静默删除该通道。
- **沿用已有参数**：从时间轴兼容的旧工程转移原调音，不是新的声学拟合。

独立调音的沿用模式要求音符起点、时长、音高逐个精确对应，并且一一匹配；缺音、多音、歧义或时间偏移会停止。作者已有的有限幅度不会仅因超过拟合器的名义范围而被删除。兼容旧文件接口和旧任务重生成时，可明确使用历史容差，但仍要求完整一一对应，并记录每一处偏移，不再允许多对一覆盖。

参考映射遇到所选通道已有非零声部／音符偏置时会停止，避免把新曲线与旧偏置静默相加；可保留原表现或为当前设置重新实测校准。同角色的多条轨道可分别指定参考音频，缓存按实际轨号隔离；实测配置仍须分别满足当前乐谱与声库设置。

四种来源互斥。之后可显式叠加风格与局部音高增量，最后统一保形加密一次、校验保护范围，再提交一份候选。校准后又加风格时，校准预测指标只对应原拟合阶段，不能冒充最终候选的声学结果。

源对象不被修改。保留、风格和加密路径保留原控制点坐标；风格可以按回执记录改变选定位置的值。参考映射与实测校准属于明确选择的通道替换，会分别记录替换前后哈希与点数，原曲线仍可从输入快照恢复。加密保留原函数形状，与改动表现分开；支持有限浮点坐标并保留原坐标类型，不截为整数。未知通道、retakes、未选轨和乐谱保持保护。已有非线性曲线无法安全处理时保留并记录部分应用；不擅自改成另一种插值。当前支持未裁剪的mainGroup；库组编排请先在编辑器中准备独立副本。

## 快照、恢复与缓存

每个会话在 `inputs/source.svp` 保存原始字节。重试、改风格和缓存失效都从此快照开始，不从上次候选继续叠加。设置变化会产生另一份带签名的结果。缓存命中先核对实际文件，不再次提交工程。手工改过的候选与损坏回执会先保留，再恢复生成结果。提交前的取消和校验失败不覆盖源文件或旧候选。

工程已提交后，回执写入或进度通知异常不会丢弃已保存的候选。缺回执会明确显示“待补全”；按原条件重试可核对哈希后补全元数据，不再次叠加调音。此时可以打开候选，但须通过回执验证后才能登记。源文件、设置、依赖或候选被外部改动时，不能直接补元数据。校准也采用此边界：已保存但缺拟合报告的工程可点击“补全校准报告”，重开会话后仍可发现这一入口；报告未验证时不会启用新的校准配置。

原始工程仍在但已外部修改时，请明确重新导入新版并新建会话；原文件不在时，校验通过的快照仍可恢复。参考音频、校准配置与试音、沿用工程、相关源码均参与缓存签名，并在提交前重新检查。同一会话禁止并发运行。

结果保存在 `outputs/tuned-<签名>.svp`，相邻 `.svp.tuning.json` 为回执，另有会话状态与选项文件。为保证换目录后仍指向同一伴奏，相对引用会规范为原音频位置，不修改音频或输入快照；请保留那些媒体文件。登记为某任务的正式调音工程是独立用户操作，生成候选不会自动替换发布选择。

旧任务和校准会话的文件接口继续保留。旧请求若同时记录多种参数来源，适配层按“实测校准 → 沿用参数 → 参考映射”的已记录优先级选择，不再先后覆盖同一组通道。新独立调音选项直接拒绝来源冲突。

## 程序化调用

使用应用根目录与自带Python；`src/`是规范源码，根模块是生成的运行副本。

```python
from tuning_workflow import create_session, run_session

session = create_session("song.svp", "new-tuning-session")
result = run_session(session, {
    "expression_mode": "preserve",
    "track_indices": [0],
    "performance_style": "power_pop",
    "style_strength": 0.6,
    "style_pitch": True,
    "expression_density": "dense",
})
print(result["output"])
```

也可运行 `tuning_workflow.py --session PATH --options options.json`。风格数值的实验边界见[风格预设](StylePresets.zh-CN.md)。工程保护与功能通过不能证明声学改善或保证听感没有失真，仍需在目标声库中实际试听。
