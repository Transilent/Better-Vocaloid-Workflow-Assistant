# 准备工作流与调音工作流

[English](TuningWorkflow.en.md) | [简体中文](TuningWorkflow.zh-CN.md)

主流程为 **准备工作流 → 调音工作流 → 简易混音 → 合成视频 → 发布**。视频合成继续可选，已有成品视频可直接进入发布。声库合成与最终发布仍由用户执行确认。

准备工作流负责在线/本地音乐、分离结果、歌词、MIDI和编辑器工程导出。保存的调音偏好不会自动作用于新准备的工程。兼容音符重生成时沿用已有参数仍是保留原调音，不等于重新拟合。

调音可选已有任务工程，或导入 Synthesizer V Studio 1／2 的 SVP、OpenUtau 的 USTX、VOCALOID 5／6 的 VPR、ACE Studio 的 ACEP 或 UFData 交换谱。在单轨卷帘或多轨视图中按歌词定位、编辑选区，并另存为同格式的候选。

USTX 0.5 可预览，编辑前请用 OpenUtau 另存为较新格式。USTX 和 VPR 的风格处理在**保留原表现**下写入各自支持的力度与音高曲线。请在原编辑器中重开并试听。

## 改词与改音符

打开可编辑的演唱轨，在单轨卷帘中：

- **改词**：双击音符，或选中后按 F2。Enter 保存，Tab 前往下一个可改词的音符，Shift+Tab 回到上一个。离开输入框时保存有效输入，Esc 取消。
- **贴整句词时**，按住 Shift 拖选一句的完整音符，点击搜索框旁的「整句贴词」，粘贴后点「核对配对」。逐个检查或修改新词，也可以保留某颗音符的原词。预览会标出多余或缺少的词、多音字、同轨重叠和受保护的发音。延音、换气和原生标记保留，跳过这些槽位继续配对。确认后整句一次写入草稿，Ctrl+Z 可一次撤销。
- 也可以先多选具体音符再贴词。核对只列所选音符。点核对中的时间可去卷帘看对应音符，再点「继续贴词」返回原核对。改变选中音符后需重新核对配对。
- 搜索框旁的**检查编辑问题**会列出当前轨的重叠、受保护发音和最近一次编辑失败。点击一项可定位对应音符。
- 单轨默认使用「改音符」。横拖音符移位置，竖拖改音高，拖右端改时长。单击音符可在右侧直接输入音高和起止时间。空白处拖出矩形可多选，Ctrl 单击增减音符，Shift 单击选择两音符之间的一段。选中的音符一起移动和拉伸，上下键升降半音，加 Ctrl 升降八度。整组改动一次保存和撤销。
- 左右键选择相邻音符，视口会跟随。Ctrl+F 找词后按 Enter 定位，用「上一处」「下一处」在匹配位置之间跳转。中键拖动画布或参数轨可平移，滚轮缩放，Shift 加滚轮横移，Alt 加滚轮查看其他音高。音符拖动时按 Alt 临时跳过吸附，按 Esc 取消未松手的编辑。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。
- 需要添加风格区间时，点击「框选风格」再拖动。多轨编排可在上方泳道直接框选，应用对象取决于已勾选的轨道。「框选即应用」开启时松手保存片段，Shift 拖动只选择时间。点击卷帘上方的色条，可在右侧调整片段的强度、唱腔和风格细节。用「新片段」切回下一段的设置。
- **保存**：修改自动进入此工程的草稿；「预览」核对改动，「生成」和「另存」得到同格式副本。只改词或音符时只提交这些改动；已应用的风格片段跟随原有音符。改动后，旧候选会标记为过时并继续保留。

支持已有音符：USTX 0.6–0.10、符合条件的 SVP／SV2、VOCALOID 5／6 VPR、ACEP（JSON/Zstd、工程结构 9／revision 0）和 UFData v1。共享、移调、裁剪和原生曲线会按格式保护相关音符，界面会显示受限原因。移动、拉伸不会越过片段边界或造成同轨重叠。改谱使用「保留原表现」。

- **VPR**：改词时同步写回原语言的发音。日语可用假名或对应罗马字；普通话可用发音唯一的单字或无声调拼音；也可复用同轨同语言已有的明确发音。锁定的发音保持原样；已有音素位置时，新发音必须能沿用原来的音素数量。原生直绘音高保持保护。
- **ACEP**：保留自定义发音、冻结音节及手工时序，按裁剪边界限制移动。ACEP2 仍只读，可从 ACE Studio 导出 UFData 后再改。
- **UFData**：保留已有发音。音符移动和拉伸不得碰到已有音高曲线；绝对音高覆盖的音符会锁定音高，已有相对曲线则保留原偏移。

## 风格和手绘音高

点击搜索框旁的「参数轨」展开音高编辑区。它与卷帘共用时间视口、选区和游标，打开后可直接画直线。1/4、1/8 或 1/16 拍格按工程变速表显示，音符移动可按拍吸附。手绘时间按原生刻度落点，开启「吸附」时偏移每 10 音分一档。

参数轨可分别显示原生曲线、预览计算的风格线和手绘偏移。编辑时使用 ±200 音分范围，「查看」显示可见曲线的全幅。用「直线」或「画笔」拖动画入当前音符，越过边界时停在该音符的安全范围。用「节点」点击手绘线来加点，拖动圆点调整时间和高度，右键删除节点。用「橡皮」点按可擦掉整段手绘，拖动可擦掉局部。单次操作共享一份草稿和撤销记录。

改风格或音符后点「预览」更新风格线。单独修改手绘时可继续参照已计算的风格线，生成候选前重新预览以应用最新草稿。

在单轨卷帘点画笔，沿一个演唱音符拖出音高偏移，松手写入草稿。点击「改音符」回到音符编辑。青色线是手绘标记，彩色条是风格片段。手绘限定在音符内，偏移为 ±200 音分。「吸附」开启时每 10 音分一档，按住 Alt 可临时跳过。Esc 取消正在画的一笔。

手绘范围内，用手绘偏移替代风格音高偏移，并与原工程的音高曲线叠加。原来的颤音以及风格的力度等参数保留；笔触两端有短过渡。换风格或强度不会重写笔触。青色线表示偏移意图，合成后的音高需在原编辑器确认。

用橡皮单击笔触的时间位置可擦掉一整段，拖动可擦掉局部，生成时重新使用该处原曲线和风格。每次绘制或擦除都能和音符、风格一起撤销。笔触随所属音符移动；缩短音符会让笔触超出范围时，先擦掉越界的部分。

手绘写入符合条件的 USTX PITD、SVP 线性 pitchDelta、VOCALOID 5/6 VPR 弯音、ACEP 数据型音高偏移，以及 UFData v1 的绝对或相对音高。VPR 按现有弯音灵敏度写入，超出范围请减小偏移；ACEP2、直接音高锚点和不支持的曲线保持保护。笔触或过渡碰到需要保留的原生断点时，预览会提示调整。核对笔触数量后，另存同格式的新工程。

## ACE Studio 调音试用

- **ACEP（JSON/Zstd、工程结构 9／revision 0）**：可在「保留原表现」下编辑已有音符，并给选定片段应用风格音高和手绘偏移；歌手、效果、未编辑的音符、其他参数及媒体引用保持原样。原生手绘锚点、裁剪穿过音符、共享和重叠片段会受保护。生成后点「另存 ACEP…」，选择原工程目录中的新文件名，再在 ACE Studio 中打开副本。工程的 `Samples` 仍由原目录提供。
- **ACEP2 和其他未核验的 ACEP 版本**：能识别的工程结构可浏览，无法识别的容器或连续速度曲线会给出 UFData 提示。ACEP2 暂不写回。
- **UFData**：在 ACE Studio 用「文件 → 导出 MIDI」选择 UFData，可带出音符、歌词及可用的发音信息。在 VWA 改谱或添加局部音高并另存 UFData，随后在 ACE Studio 的原工程中导入交换文件。它不携带原歌手、伴奏、混音效果或 ACE 专用表现参数；编辑器是否采用导回的音高仍需在实际版本中核对。

## 统一处理顺序

支持完整参数来源的 SVP 可四选一；其他格式以调音页的可选项为准：

- **保留原表现**：保留工程已有参数。
- **参考演唱映射**：由明确对应声部的音频生成所选力度、张力、气声、发声强度草案，不是克隆音色。
- **实测声库校准**：使用同乐谱、声库和渲染设置的配置，仍需用户先渲染试音。配置缺少某个原有参数通道的试音时，不能静默删除该通道。
- **沿用已有参数**：从时间轴兼容的旧工程转移原调音，不是新的声学拟合。

独立调音的沿用模式要求音符起点、时长、音高逐个精确对应，并且一一匹配；缺音、多音、歧义或时间偏移会停止。作者已有的有限幅度不会仅因超过拟合器的名义范围而被删除。兼容旧文件接口和旧任务重生成时，可明确使用历史容差，但仍要求完整一一对应，并记录每一处偏移，不再允许多对一覆盖。

参考映射遇到所选通道已有非零声部／音符偏置时会停止，避免把新曲线与旧偏置静默相加；可保留原表现或为当前设置重新实测校准。同角色的多条轨道可分别指定参考音频，缓存按实际轨号隔离；实测配置仍须分别满足当前乐谱与声库设置。

四种来源互斥。之后可显式叠加风格与局部音高增量，最后统一保形加密一次、校验保护范围，再提交一份候选。校准后又加风格时，校准预测指标只对应原拟合阶段，不能冒充最终候选的声学结果。

源对象不被修改。保留、风格和加密路径保留原控制点坐标；风格可以按回执记录改变选定位置的值。参考映射与实测校准属于明确选择的通道替换，会分别记录替换前后哈希与点数，原曲线仍可从输入快照恢复。加密保留原函数形状，与改动表现分开；支持有限浮点坐标并保留原坐标类型，不截为整数。未知通道、retakes 和未选轨保持保护；乐谱仅按明确提交的改谱操作变动。已有非线性曲线无法安全处理时保留并记录部分应用。

## 快照、恢复与缓存

每个会话在 `inputs/source.<格式>` 保存原始字节。重试、改风格和缓存失效都从此快照开始，不从上次候选继续叠加。设置变化会产生另一份带签名的结果。缓存命中先核对实际文件，不再次提交工程。手工改过的候选与损坏回执会先保留，再恢复生成结果。提交前的取消和校验失败不覆盖源文件或旧候选。

工程已提交后，回执写入或进度通知异常不会丢弃已保存的候选。缺回执会明确显示“待补全”；按原条件重试可核对哈希后补全元数据，不再次叠加调音。此时可以打开候选，但须通过回执验证后才能登记。源文件、设置、依赖或候选被外部改动时，不能直接补元数据。校准也采用此边界：已保存但缺拟合报告的工程可点击“补全校准报告”，重开会话后仍可发现这一入口；报告未验证时不会启用新的校准配置。

原始工程仍在但已外部修改时，请明确重新导入新版并新建会话；原文件不在时，校验通过的快照仍可恢复。参考音频、校准配置与试音、沿用工程、相关源码均参与缓存签名，并在提交前重新检查。同一会话禁止并发运行。

结果保存在 `outputs/tuned-<签名>.<格式>`，相邻的 `<文件名>.tuning.json` 为回执，另有会话状态与选项文件。SVP／USTX 候选保留伴奏指向；ACEP 保持原相对引用，另存时使用原工程目录。若需登记 ACEP，在「任务与结果」手动选择已经另存的副本。生成候选不会自动替换任务选择。

旧任务和校准会话的文件接口继续保留。旧请求若同时记录多种参数来源，适配层按“实测校准 → 沿用参数 → 参考映射”的已记录优先级选择，不再先后覆盖同一组通道。新独立调音选项直接拒绝来源冲突。

## 程序化调用

使用应用根目录与自带Python；`src/`是规范源码，根模块是生成的运行副本。

```python
from tuning_workflow import create_session, run_session

session = create_session("song.svp", "new-tuning-session")
result = run_session(session, {
    "expression_mode": "preserve",
    "track_indices": [0],
    "performance_style": "power_pop",
    "style_strength": 0.6,
    "style_pitch": True,
    "expression_density": "dense",
})
print(result["output"])
```

也可运行 `tuning_workflow.py --session PATH --options options.json`。风格数值的实验边界见[风格预设](StylePresets.zh-CN.md)。工程保护与功能通过不能证明声学改善或保证听感没有失真，仍需在目标声库中实际试听。
