# VWA artwork

[English](ArtAssets.en.md) | [简体中文](ArtAssets.zh-CN.md)

`assets/headphone-character.png` is a transparent, pale lavender sidebar illustration. It was generated with the built-in image generation tool from the user's supplied crop of the VWA concept. The accepted direction preserves the faint side profile, headphones, broad shaded shapes and flowing hair. Earlier detailed and redesigned character versions are not used.

`assets/moonlight-background.png` is a separate, opaque, low-contrast blue/lavender mist texture generated from the application-shell palette. It contains no controls or media preview. The application caches its composition, reduces its contribution in dark mode, and skips it in solid mode. Missing files retain the procedural fallback.

The character has no interactive or task-state role. It is enlarged and composed into the cached background with no independent character switch or widget. Short windows reduce its contrast beneath navigation. The PNG source alpha is retained; solid reading mode omits decorative art. Standard window controls and all workflow data remain separate from the artwork.

These are AI-generated project assets distributed under the repository's LICENSE. They are not third-party stock downloads. Existing third-party licenses are unchanged. The existing purple vector application logo remains in use.

Material separation and legibility were informed by [Microsoft's Acrylic guidance](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic) and [Fluent 2 materials](https://fluent2.microsoft.design/material). Public illustration searches were used for visual comparison; those images are not bundled with VWA. No system-level Acrylic implementation is implied by this artwork.
