## 可复现检查

审查问题的定向回归还覆盖：关闭导出后保存预设、重启及恢复任务；空音频导出与命令行；原封面校验复用和离线发布准备；仅 MIDI 的 RMVPE 依赖检查；字幕长音、延续音及无关尾奏的结束时间。

在程序目录检查启动条件和已安装的固定依赖：

```powershell
& '.\dependencies\vocal2midi\python\python.exe' -B .\launch.py --check
& '.\dependencies\vocal2midi\python\python.exe' -B .\check_dependencies.py --full
```

回归测试请在安装好运行库的源码目录执行：

```powershell
& '.\tools\Prepare-Source.ps1'
& '.\dependencies\vocal2midi\python\python.exe' -B .\tests\run_tests.py
```

## 发行验证

旧客户端不会因同一个下载包中新增了模块而自动扩充白名单。`packaging/update-clients.json` 固定原版客户端及其源码哈希，直接更新包的构建工具会拒绝它们不支持的目标文件。[更新兼容协议](UpdateProtocol.zh-CN.md)提供经过校验的安装器引导包、按运行库匹配的增量，以及其余已发布客户端使用的规范 `VWA-Updater.exe` 路径。当前客户端完整暂存后重启一次安装；原版 0.4.0／0.4.1 保留迁移窗口流程。兼容回归采用模拟发布信息和小型依赖素材，运行原版客户端代码，并启动无控制台 `VWA-Updater.exe`，不下载新的公共发行包，也不衡量模型准确率。生成交付压缩包仍须先通过用户测试确认。

打包前可运行 `tools/verify_portable_layout.py`，按精简清单建立临时测试目录，使用该目录的 Python 运行回归。被排除的依赖在该目录中确实不存在；大体积只读资产使用 NTFS 硬链接，可能写入的文件复制。验证完成后删除测试目录，不生成交付压缩包。另用短合成音频实际检查 MDX 的 CPU、DirectML、时间长度、分轨重建和结构化片段进度。固定推理结果及短合成音频不衡量歌词或歌曲准确率。

将完整 ZIP 解压到独立目录，逐个核对 CRC、大小、SHA-256，并与固定依赖清单交叉检查。使用解压后的 Python 检查启动并运行回归。当前包的分卷与完整 ZIP 哈希保存在对应的 `portable-metadata-full.json` 或 `portable-metadata-jpn.json`；顶层 `release-assets.json` 的 `archive` 与 `parts` 仍是为固定 `Install-Runtime.ps1` 路径保留的 BVWA 根目录兼容元数据。

实际模型验证覆盖本地分离、歌词识别和双声部 MIDI。短素材测试不能证明任意歌曲的准确率。发行报告不包含账号、私人素材或本机安装路径。

可选组件另外经过 CPU、CUDA 真实下载与原模型加载验证。中日文短样本从离屏界面的“开始处理”进入 CUDA 分离并生成纯音符双声部 MIDI。这验证集成及文件结构，不衡量歌词或音乐准确率。保留的 ASR 路径由原有识别回归覆盖。

## 限制

- 文件校验通过仍需在新电脑检查启动，硬件、驱动和安全软件可能不同。
- 分离可能串音，和声较弱时会漏音或空轨。
- 歌词和音高需要人工校正，参考歌词也不能保证正确。
- 本地网页测试验证适配逻辑，平台更新可能改变实际兼容性；新电脑需重新登录。
- 助手准备上传页面，不检查所有平台字段，也不自动发布。

## 任务与文件契约测试

`test_task_contract.py` 使用真实的本地音频及外部分轨流程，覆盖文件修改、旧回执迁移、声部和格式的部分成功、阶段失败、人工成果版本、清单恢复、跨任务清理保护、越界路径和跨进程提交。`test_task_contract_ui.py` 离屏运行实际对话框，结合 FFmpeg 生成的音视频验证任务跳转和发布状态。工程导出回归还检查新一轮导出中缓存格式的状态。这些测试验证文件和状态处理，不代表音乐识别准确率，也不代替创作平台的在线兼容性测试。
