# VWA 术力口工作流助手使用指南

[English](UserGuide.en.md) | [简体中文](UserGuide.zh-CN.md) | [README](../README.zh-CN.md)

## 输入

紧凑准备布局、独立调音、外观设置与结果状态见[VWA工作空间](Frontend.zh-CN.md)。

完整便携目录已带运行库。全量包为 `VWA-Windows-x64.zip`，JPN 包为 `VWA-Windows-x64-JPN.zip`。使用分卷时，请配合对应的 `portable-metadata-full.json` 或 `portable-metadata-jpn.json` 及该包附带的合并工具。源码目录可用 `tools/Start-Diagnostics.bat` 安装依赖，并优先读取本目录或上一级的任一完整 ZIP，否则下载 Release 便携包。安装校验依赖哈希，保留助手设置、任务和登录会话；中断后再次运行诊断脚本即可继续。

进入解压后的顶层文件夹 `VWA`，双击 **`VWA.exe`**，打开“准备工作流”。“音乐来源”支持“B站 BV 号 / 链接”和“本地音乐文件”。“选择文件”打开文件选择器。本地输入无需 BV，先保存副本再解码，原文件不变。原文件移动后仍可从副本继续任务。

## 升级

VWA 1.0.0 的全量包为 `VWA-Windows-x64.zip`，JPN 包为 `VWA-Windows-x64-JPN.zip`。已有安装可通过**设置与更新**下载并安装兼容的程序更新；提供的更新支持时，会保留设置、任务、登录会话、已安装模型和可选组件。

仍在旧版 BVWA 协议别名上的已发布客户端，可按发行说明运行 **`VWA-Updater.exe`** 使用兼容工具。单独的更新 ZIP 不能作为完整安装包。升级前请备份正在编辑的工程。

## 保存目录

在准备页“输出内容”中点击“选择目录”，或输入新的文件夹路径。此目录用于整个任务，与是否导出音频无关。默认使用助手目录的 `jobs` 文件夹。每个任务会新建独立子文件夹，保存下载的视频（BV 输入为 `video/source.mp4`）、音频和 MIDI。助手会记住所选目录及以前的任务位置；继续任务沿用原目录，重新处理则在当前选定目录中新建任务。

## 分离与识别

歌词与音符位于准备工作流，字幕工具从该区域打开，缓存管理位于设置与更新。顶部“设备设置”选择处理设备，“歌词与音符”调整提取步数。日志按需展开。

| 选项 | 用途 |
| --- | --- |
| 自动分离 · 主唱 / 和声双轨 | 两级分离，分别识别主唱、和声 |
| 导入外部分轨 | 使用完整主唱、和声、伴奏 WAV |
| 合并人声 · 单轨 MIDI | 只提取合并人声 |
| 中文 / 日语 | 歌词处理语言 |
| 中文歌词格式 | 汉字或拼音，同时用于主唱与和声 |
| 识别歌词并写入 MIDI | 关闭时只提取音符 |
| 准备工作流 → 歌词与音符 → 提取步数 | 选择 8、16 或 32 步 GAME |

外部分轨需来自同一输入，从 0 秒导出完整范围，保留开头静音。单声道和 48 kHz WAV 会转换；长度不符会拒绝。长度相同不能证明没有整体偏移。

在“歌词与音符”搜索网易云歌词，或导入／填写本地歌词。主唱与和声分别填写，留空时独立识别。参考文本会去除空格、标点和换行，请只保留演唱内容。

## 可选模型组件

在“模型与组件”选择 CPU 或 NVIDIA GPU / CUDA，点击“下载并安装”。下载量约
为 0.46 GB 或 3.52 GB，安装后约需 1.56 GB 或 6.14 GB。界面显示安装与临时
下载所需空间。基础环境保留；同一时间只保留一份可选推理环境。

下载使用固定版本及 SHA-256 校验，支持取消和续传。验证失败不会启用不完整组件。
重试可继续下载；修复已安装环境可用“更多 → 重新安装所选运行库”。

安装成功后点击“使用此模型”，或在处理页选择 BS-RoFormer。顶部“设备设置”可指定
新模型设备：自动模式优先可用 CUDA，否则使用 CPU；明确指定 CUDA 而不可用时会报错。
Karaoke 2 可直接使用。迁移助手时保留完整 `dependencies/optional` 文件夹。

模型按音乐角色分离，不按歌姬身份识别。需试听串音、漏音及错字；更多步数不能保证更高准确率。

中文歌词使用 Qwen ASR；日语保留包内 Romaji ASR，再由 HubertFA 对齐，选择日语不会改用 Qwen 权重。识别为空或对齐不可用的片段保留仅音符结果，并写入对齐报告；单个片段出错不会丢弃其他已对齐片段。日语短音节修复不会跨过超过 150 毫秒的停顿。

## 运行与恢复

“开始准备”新建任务。在“任务与结果”选中任务，用“继续 / 重试”沿用保存参数；
“用当前工作流重做”按当前工作流新建任务并复用输入。“取消处理”在运行时显示，
模型最多等待 30 秒后强制停止；“打开结果目录”查看选中任务。

输入、设置变化或 MIDI 损坏使相应缓存失效。主唱完成后可只续跑和声。静音和声会输出空轨并提示。

## 结果

| 任务内文件 | 内容 |
| --- | --- |
| `audio/source.wav` | 完整解码原音频，44.1 kHz 双声道浮点 WAV |
| `audio/lead.wav`、`audio/backing.wav` | 主唱、和声 |
| `audio/instrumental.wav`、`audio/vocals.wav` | 伴奏、合并人声 |
| `midi/voices.mid` | 两个声部音符轨及速度元数据 |
| `midi/lead/lead.mid`、`midi/backing/backing.mid` | 单独导入的声部 MIDI |
| `midi/vocals.mid` | 单声部结果 |
| `midi/lead/lead_alignment.json`、`midi/backing/backing_alignment.json` | 片段秒数、对齐覆盖与回退原因，不含歌词原文 |
| `midi/需要核对的音符.csv` | 按秒记录的核对提示，不自动改音高 |
| `original-cover.*` | BV 输入的本家封面 |
| `status.json` 与日志 | 步骤和诊断 |
| `exports/voices.ustx`、`voices.vsqx`、`voices.svp` | 编辑器工程，可保留音高线 |
| `exports/audio/` | 所选压缩音频格式；WAV 使用 `audio/` |

在 **歌词与音符** 中开启 **手动指定 BPM**，可设置 20–400 之间的固定速度，支持小数。该设置适用于 MIDI 与三种编辑器工程，并随预设和任务保存。音符、音高线和伴奏的实际时间保持一致，不拉伸音频，也不量化。关闭时沿用 120 BPM 时间基准，不自动检测歌曲速度，暂不支持变速图。继续旧任务保留原设置；修改后请使用“用当前工作流重做”。命令行可使用 `--bpm 137.5`。

在 VOCALOID 6 中，先建工程，再使用“文件 → 导入”载入 `voices.mid` 或单独声部 MIDI。“打开”用于工程文件。导入对话框若提供歌词编码选项，请选 UTF-8；6.2 起支持读取 MIDI 内的歌词。参见[官方手册](https://rsc-net.vocaloid.com/assets/pdf_files/bb/VOCALOID_Reference_Manual_ENG.pdf)与[MIDI 导入说明](https://www.vocaloid.com/en/support/faq/617)。

## 发布工作流

**发布**位于可选的**合成视频**之后，每次显示一个完整步骤：

1. **成品与来源**：选择成品视频和来源任务，或通过 BV 读取本家资料。
2. **视频封面**：大图预览本家原始封面，也可选择图片或视频画面。本地音乐任务需要自选图片，或另行读取 BV 来源。
3. **标题与简介**：同时编辑两平台文案，应用标题格式与署名，并核对字数和 STAFF。
4. **账号与上传**：点击“生成发布资料”，登录后点击“上传所选平台”。主按钮固定在底部，滚动内容时仍可操作。

底部的上一步、下一步和步骤编号用于切换页面；点击下一步时会检查当前必填内容。各平台分别提供登录、继续填写和关闭任务入口，不可用的操作会禁用。登录完成后关闭登录窗口；上传后保留创作页面，由用户检查并手动发布。

本家封面从视频资料读取，截图与自选图片是独立选项。适配 4:3 和 16:9 比例时按需补边，保留完整原图。

修改成品、封面或文案后，需要重新生成发布资料。“继续填写当前上传”可更新仍打开且视频相同的上传页面。浏览器关闭后需重新上传。发布前请在创作页面核对分区、标签、署名和其他必填项。

## 命令行与诊断

在解压后的程序目录执行：

```powershell
& '.\dependencies\vocal2midi\python\python.exe' -B .\pipeline.py --source 'BV_IDENTIFIER' --voice-mode dual
& '.\dependencies\vocal2midi\python\python.exe' -B .\pipeline.py --audio-file 'D:\Music\song.mp3' --voice-mode dual
& '.\dependencies\vocal2midi\python\python.exe' -B .\pipeline.py --job 'JOB_FOLDER'
& '.\dependencies\vocal2midi\python\python.exe' -B .\separate_audio.py --input 'INPUT_AUDIO' --output 'EMPTY_OUTPUT_FOLDER'
```

`--notes-only` 仅音符；`--midi-steps 8|16|32` 设置步数；`--until separation` 在 MIDI 前停止。三种输入参数互斥。本地分离输出目录必须为空。

独立 `separate_audio.py` 工具位于源码仓库。便携版命令行分离可使用
`pipeline.py --until separation`。

诊断批处理位于 `tools/`。
`Check-Dependencies.bat` 校验依赖；启动错误见 `launcher.log`。
CPU/GPU 切换脚本修改基础 CPU / DirectML 设置，重启后生效。

`cache/` 保存临时文件和专用登录会话，`jobs/` 保存音频和 MIDI，`publish-packages/` 保存封面、发布文本及成品视频的路径与哈希，不复制完整成品。上传前请保留成品文件；移动或修改后需重新生成发布资料。这些目录不进入 Git 或干净发行包。每台新电脑需重新登录。

## 下载与程序更新

“模型与组件”提供自动、官方和优先加速三种下载方式；“设置与更新”可设置默认方式。GitHub 文件通过 GitProxy 加速，Hugging Face 模型通过 HF-Mirror 加速，其他依赖使用官方源。连接失败时，自动和优先加速模式会尝试另一来源。文件大小及 SHA-256 校验始终启用。

自动更新只在启动时执行。默认检查兼容的程序更新，下载并校验后提供 10 秒倒计时，随后自动重启安装。可暂缓安装，或在“设置与更新”关闭相应选项。开始使用助手后，安装会推迟到下一次启动；正常使用期间不定时检查更新。手动检查或下载的更新，需要点击“重启并安装更新”才能应用。安装保留任务、配置、平台登录和可选模型；替换失败会恢复原程序。需要更换基础运行库时，界面会提示下载完整便携包。仍在旧版 BVWA 别名上的客户端，可按发行说明运行 `VWA-Updater.exe` 使用兼容路径。

## 工作流、任务与恢复

**准备工作流**顶部并列显示音乐来源和输出内容；处理方式的常用选择直接可见，分离模型与外部分轨路径可展开。主要区域为**歌词与音符**：左侧切换主唱／和声文本，右侧配置识别与音符。字幕工具从同一区域打开。小窗口按单列滚动。顶部的**设备设置**集中选择各引擎的处理设备。预设保存语言、模型、设备与导出格式，不包含歌曲路径或参考歌词。

侧栏前四项为准备工作流、调音工作流、合成视频、发布。独立调音可选择已有任务的SVP或导入SVP，生成独立、可恢复的候选，参数来源与曲线保护方式见[调音工作流](TuningWorkflow.zh-CN.md)。之后为模型与组件、任务与结果、设置与更新。外观设置提供浅色／深色、月光玻璃／纯色阅读与界面缩放，保留系统标题栏和常规操作。

“设备设置”还提供共用的“DirectML 显卡”和“CPU 线程数”。自动模式优先选择独立显卡，并保留各引擎的默认线程设置。指定线程数会限制相关 CPU 运算的线程数量；线程更多不一定更快。这些选项随预设保存。

关闭“生成 MIDI 与工程”即可只处理音频；编辑器工程也可单独关闭，仍保留标准 MIDI。工程支持 USTX、VSQX、SVP，可保留 RMVPE 音高线并引用伴奏。音频支持 WAV、FLAC、MP3、OGG，WAV 直接使用任务音频。合成歌声需要在编辑器中渲染。

分轨峰值超出音频范围时，FLAC、MP3、OGG 会共享必要的峰值衰减，保持人声与伴奏之间的音量关系。增益记录在 `exports/report.json` 中，原始浮点 WAV 保留完整信号。

关闭工程或音频导出后，已选格式及参考演唱参数仍随预设保存，重启后也会保留；重新开启即可恢复。关闭的选项不参与本次导出。内部处理所需的 WAV 分轨会保留，关闭音频导出不会删除它们。命令行可使用 `--no-audio-export` 不选择音频导出。

**任务与结果**支持搜索、筛选、重命名、查看日志和重试。继续任务使用其记录的参数；**用当前工作流重做**使用当前预设创建新任务。进度显示已完成阶段、耗时和可测量的子任务。复用结果前会校验文件，设备错误可改用 CPU 继续。

## 缓存管理与歌词字幕

MIDI 字幕的句尾按所选声部的音符结束时间确定，也会衔接同一歌词下连续的转音。无关的文件尾部空白或其他声部不会延长末句。只有歌词时间、没有对应完整音符的片段，仍需核对建议的字幕结束时间。

重新处理任务时，会校验并复用来源一致的原封面缓存，发布准备可离线使用这张封面。缺少有效原封面不影响音乐处理；补取封面需要联网，也可选择自定义图片。

导出文件与记录的内容不同时，重新生成前会将原文件保存到任务的 `backups/` 文件夹，并在报告中记录位置。直接修改 MIDI 或工程后也能保留编辑内容；未修改的正常结果不会额外备份。建议把正在调音的工程另存为工作文件。

在**设置与更新 → 缓存与磁盘**中扫描占用，选择可再生成的缓存后清理。任务结果、模型、预设和登录信息会保留。下载及未完成的分段缓存可在相关操作结束后清理。

WAV 导出直接使用任务中已有的音频，压缩格式另行保存。继续任务会校验结果，损坏的导出文件逐个修复。读取本家资料和原封面无需下载完整视频，截帧或访问原视频时再下载。

“模型与组件 → 中文歌词识别 → 校验 / 恢复中文模型”会校验原始 Qwen 权重并下载缺失或损坏的文件。这部分模型约占 4.38 GiB，完整运行库已包含。日语与纯音符提取只检查各自需要的模型，可独立运行；缓存清理不会删除已安装权重。

**歌词与音符**中选择**网易云匹配**，可搜索歌名和歌手或粘贴歌曲 ID／链接，选中的原文歌词默认填入主唱；选择**本地填写**，可导入 LRC／YRC／TXT 歌词或直接填写，留空时从对应人声音频本地识别。两个来源分别保留主唱文本，网易云匹配不会覆盖和声歌词。参考文本会与人声音频对齐，歌曲时间戳不会直接移动 MIDI 音符。

**歌词转字幕**卡片分为**网易云匹配**与 **MIDI 匹配**：前者使用歌曲已有的歌词时间轴，后者使用 MIDI 歌词事件与速度变化。导入多轨 MIDI 后可选择声部，两个来源各自保留编辑内容。核对文字、时间和整体偏移后导出 UTF-8 SRT／WebVTT。没有时间轴的纯文本不能直接生成字幕，不会按总时长均分。字幕匹配不覆盖音乐提取使用的参考歌词。

## 文件与下一步

在**任务与结果 → 文件与下一步**中校验生成文件及其依赖，登记调音完成后的工程和 Mixdown，再进入可选的视频合成。已有成品视频时，可以直接进入发布工作流。上游文件改变后，旧的后续登记会提示核对；取消登记不会删除原文件。重建清单会保留备份和人工登记。旧任务迁移与清理保护规则见[任务状态与文件记录](TaskContracts.zh-CN.md)。
